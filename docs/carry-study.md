# 原生循环状态重置试点

[English](en/carry-study.md) · [研究设计](research.md) · [原生接口](native.md)

## 科学问题

在原生 DRQN 的同一学习历史上，一次清除实时循环状态会怎样改变后续行为、恢复过程和学习轨迹？实验比较同一模型的两个分支，使用相同参数、优化器、经验回放、随机状态和环境状态作为分支起点。

该试点接续 A2-P1 的包级比较，研究实时循环状态的具体作用。[归档结果](research-results.md)

## 实验设计

使用 `ForagaxSquareWaveTwoBiome-v11`、9×9 彩色观察和原生 DRQN。实验索引 23、24 按上游实验配置解析，各自形成一条独立训练轨迹。

每条轨迹先执行 150,000 次环境交互，保存共同状态及全部前史。随后建立两个分支。

| 分支 | 边界操作 | 后续交互 |
| --- | --- | ---: |
| 保留循环状态 | 从共同状态继续 | 150,000 |
| 单次重置循环状态 | 在下一次策略计算前将实时 `carry` 设为 `None` | 150,000 |

每个索引执行 450,000 次交互，两索引合计 900,000 次。两个分支共用已执行的前史。实验边界按环境交互计数，agent 的更新时钟保留其原生取值与调度。

重置操作只改变实时循环状态。已有经验回放中的状态、参数、目标参数、优化器、随机状态、探索参数、奖励轨迹、上一条转移和环境状态均保持共同起点。分支运行后产生的新行为、回放与学习变化构成干预响应。

## 主要测量

对每个索引计算环境交互区间 `[150000, 300000)` 的平均奖励，并报告

```text
R_i = 平均奖励(单次重置循环状态) - 平均奖励(保留循环状态)
```

分别呈现 `R_23`、`R_24` 及其算术平均值。索引是分析单位，两个分支保留配对关系。

## 次要测量

- 每 25,000 次交互的奖励均值。
- 分支后每 50,000 次交互的 loss、绝对 TD error 和 weight change 均值，使用 float64 归约。
- 环境变化前后各 64 次交互的奖励差，窗口完整位于 `[150000, 300000)`，按时间顺序选择互不重叠的完整窗口，相邻窗口可首尾相接。
- 以变化前奖励均值的 90% 为恢复水平，按 64 步块检查，观察上限为 2,048 次交互。90% 按变化前均值直接相乘计算，保留零值和负值的原义。恢复观察延伸经过后续环境变化。
- 各分支合格环境事件数、恢复与未恢复数量、环境状态占用和运行资源。
- 重置前、重置后及首次后续策略计算后的实时循环状态大小。

loss、绝对 TD error 和 weight_change 按环境交互采样。原生学习步骤刷新这些诊断值，其他交互保留其当前值。

固定时间奖励对比与事件条件测量分别呈现。空事件集和未在观察期恢复的情况保留各自数量和缺失含义。

## 状态与数据

共同前史保留 rewards、biome_id、loss、abs_td_error、weight_change 五条逐步轨迹及其类型、形状与内容摘要。两臂从相同序列化状态恢复，重置前逐字段比较共同状态，重置后记录实际差异路径。

产物包括原生配置、环境版本、五条轨迹、共同检查点、两臂最终检查点、首步调度记录、配对结果和资源记录。运行与调试日志放在实验输出目录。
