## 1. 科学问题

IntelligenceDynamics 研究一个可证伪的问题：当系统必须在部分可观测、持续变化的环境中适应，并承担计算与记忆成本时，工程设计、演化搜索和自然演化是否会产生相似的动力学组织与因果作用？比较信息如何保留、计算如何分配、学习如何改变行为。

强假设是：支持广泛持续适应的计算原则具有相对紧凑的描述。弱假设是：即使没有唯一架构，也存在反复出现的组织族，例如持久状态、条件计算、子回路复用、多时间尺度和局部可塑性。

与之竞争的解释包括：不同组织可以达到相同资源前沿；共同任务、优化器或指标制造了表面收敛；共同点仅停留在“反馈、记忆、优化”等缺乏预测力的抽象层次。实验应能区分这些解释。

### 分析概念

- **状态**：影响当前行动、且不能完全从当前观测恢复的内部信息。
- **记忆**：使过去信息可在以后使用的存储和更新机制。
- **计算**：信息处理与状态转换，需要明确计量单位。
- **学习**：经验引起的行为或更新规则变化。
- **控制**：选择行动、计算资源、更新时机和停止条件的过程。

状态、记忆、计算、学习与控制可由同一动力系统实现，使用 `S[t+1] = F(S[t], O[t], A[t], M[t])` 描述其演化。条件计算是否降低重算成本、学习是否降低未来适应成本，都由匹配实验判断。

## 2. 三条研究路线

| 路线 | 研究对象 | 主要操作 | 主要比较 |
|---|---|---|---|
| A：工程与压缩 | 已具备持续适应能力的系统 | 限制资源、局部化更新、改变状态可用性、稀疏化与移除任务提示 | 能力、适应、可塑性与资源的联合前沿 |
| B：演化与发现 | 学习规则、门控、调制、记忆与组织生成规则 | 搜索可遗传参数，生命周期内学习，独立环境评估 | 学习机制搜索与固定策略搜索；不同搜索空间的预算匹配 |
| C：生物与机制提取 | 神经连接、活动与干预数据 | 提取跨实现可定义的组织指标，比较扰动响应 | 局部控制、长程协调、复用、状态持续性与资源约束 |

A 路线逐步比较任务 ID 路由、观测推断路由、持久状态路由及无显式边界的路由。B 路线对奖励密度、任务标签、全局更新和固定拓扑分别设置对照，区分单项依赖与交互效应。C 路线把材料分为结构、模拟动力学、记录活动和因果干预四类；图上的影响估计与直接神经干预回答不同问题。

三条路线使用独立的发现过程，分别记录预设结构、独立发现的组织与干预结果。所有候选模型均被预置的结构属于设计条件，其出现不计为独立涌现；该结构的因果作用通过干预另行检验。生物系统提供自然形成的比较对象，其历史约束与物理实现也是需要控制的因素。跨路线比较使用同一抽象层次的操作定义，分别呈现结构观察、动态响应和干预结果。

## 3. 假设矩阵

| 假设 | 可观察预测与主要检验 | 竞争解释或削弱条件 | 路线 |
|---|---|---|---|
| H1 资源压力促进条件计算 | 在能力相当时收紧预算，活动计算比例下降且更依赖状态 | 稀疏性由正则或架构强制；密集系统仍有相同或更优前沿 | A、B、C |
| H2 持久状态提高部分可观测条件下的效率 | 控制容量与计算后，状态保留减少历史重放并改善适应；对状态作匹配干预 | 优势来自额外容量；等预算历史窗口达到同样效果 | A、C |
| H3 持续适应促进子回路复用 | 相关情境共享功能子集，定向消融改变相应任务表现 | 复用仅由搜索奖励或预设模块产生；无复用系统同样高效 | A、B、C |
| H4 多时间尺度具有适应价值 | 快活动、中速更新和慢结构变化形成可测分离；改变时间尺度影响恢复 | 分离只是固定超参数的直接结果；单时间尺度系统同样有效 | A、B、C |
| H5 搜索学习组织优于仅搜索固定策略 | 匹配参数、候选评估和交互预算后，学习机制在新实例中更快适应 | 优势来自较小搜索空间；直接策略搜索匹配迁移能力 | B |
| H6 外部支撑可以逐步移除 | 用推断状态、局部信号或自主路由替代任务标签、密集奖励和全局更新，能力仍可保持 | 隐性监督仍在；移除后在足够搜索范围内持续失效 | A、B |
| H7 误差相关信号参与资源分配 | 干预误差、惊讶或不确定性信号会改变计算或更新分配及适应 | 信号只是伴随变量；等效系统不需要这种信号 | A、B、C |
| H8 长生命周期适应依赖持续可塑性 | 晚期仍能对标准新扰动学习；冻结更新造成可重复的适应差异 | 静态能力加有界记忆已足够；更新幅值与实际可学性脱节 | A、B |
| H9 收敛主要体现在动力学与因果作用 | 不同实现具有相近的匹配干预响应，而非相同权重 | 共同任务造成表征相似，但干预响应不一致 | A、B、C |
| H10 生物系统是一类 Pareto 解 | 部分生物组织在人工系统中复现，另一些细节可删除而不损害前沿 | 相关能力必须依赖细粒度生物结构复刻 | A、C |
| H11 充分原则可能形成有限组织族 | 多种独立实现形成稳定组织簇，并具有相应因果特征 | 聚类依赖指标选择；不存在稳定簇，或只有唯一有效架构 | A、B、C |
| H12 学习降低未来适应成本 | 再次遇到相关变化时，在维持能力的同时减少恢复交互或计算 | 只积累知识，恢复成本不降；变化本身变简单 | A、B |

优先测量持久状态、持续可塑性、条件计算、复用和时间尺度。预测编码、脉冲网络、世界模型及发展式拓扑作为候选实现家族参与比较。

## 4. 任务与信息边界

### 合成隐藏映射任务

内置任务的观测仅包含离散 cue，行动为二元选择。当前 cue 到正确行动的映射属于隐藏状态，可在生命周期内按给定时间变化。动作 `t` 的反馈在动作 `t + delay + 1` 之前送达，并携带原动作的信用编号。评估记录包含隐藏状态和即时正确性，但这些字段不传入策略。

场景库同时包含静态与切换条件，并使用相同 cue 序列、相反目标映射的镜像对。任意确定性固定 cue 策略在镜像对上的正确率均值为 0.5。镜像对照控制初始映射偏好；跨任务泛化通过多样任务分布和独立外部环境实验检验。

可遗传对象是初始偏好与更新规则参数。价值表、待反馈信用、门控窗口和累计量在每个生命周期开始时重置。训练、校准与最终评估的职责分开：搜索只读取训练场景；匹配随机门控的概率从训练数据确定；最终场景不参与候选选择或阈值调节。

### 机制比较

固定、始终更新、瞬时条件门控、泄漏累积、持续性、缓冲持续性和随机门控使用同一反馈接口。持续性需要窗口内足够多次高误差；缓冲持续性同时保留尚有效的早期信用，并在确认后提交。缓冲更新按原反馈的来源归因。

孤立扰动与突发扰动分别检验单次错误反馈和时间聚集错误反馈。扰动参数定义为尝试开始概率，实际被翻转的反馈比例另行记录。只在训练中出现孤立扰动时，突发扰动可作为未参与适应度的压力条件。

## 5. 因果干预与比较单位

### 匹配分支

在预定动作边界前只生成一次共同历史。复制环境、策略、随机状态、待处理反馈和计数器，然后检查副本一致。施加干预后、执行下一动作前，结构化差异只能落在预先声明的字段上。

- 冻结更新：保留已学价值、探索与行动接口，仅改变后续更新是否允许。
- 一次状态重置：改变指定状态而保持参数、优化器、回放、随机状态和环境不变。
- 门控记忆重置：清除累计误差、近期标记和待确认信用，不清空价值表或未送达反馈。

门控记忆重置、循环状态重置和后续生命周期持续禁用记忆分别设为独立干预。干预未改变状态时，记录为空操作。

对于晚期可塑性，可在多个预定年龄比较固定后续窗口内继续学习与冻结学习的能力差：`P(t) = mean_reward_continued - mean_reward_frozen`。该差值测量学习路径的行为价值；测试可学性时，施加可比较的新扰动，测量学习速度与可达能力。梯度、损失和权重变化作为过程量记录。

### 事件支持与固定时间支持

事件响应定义为同宽后窗口均值减去前窗口均值。若策略改变会影响事件发生，应同时报告各臂事件数量与时间戳重叠。共同支持比较先取合格时间戳交集，再用同一个确定性间隔规则选取事件。没有共同选取事件时，该共同支持比较未识别，两臂平均响应及其差值记为缺失；分别报告各臂合格事件数、共享事件数和选取事件数。

共同事件仍可能受干预影响而形成选择偏差；它是不同于固定时间效应的估计对象。固定时间块比较不以干预后的事件是否发生为条件。应明确每个差值方向，保留两类结果，不用事后选择的指标替换主要终点。

## 6. 共同测量

| 层面 | 应报告的量 | 关键解释 |
|---|---|---|
| 能力 | 奖励、成功率或正确率的分布，最弱情境，生命周期轨迹 | 任务内量纲须保留 |
| 适应 | 恢复交互数、恢复曲线面积、恢复期间计算与更新成本 | 预先定义参考水平、窗口和观察终点 |
| 可塑性 | 多年龄标准扰动的学习速度、可达能力及冻结对照 | 与遗忘和状态构建分别测量 |
| 计算 | 实际活动操作、满激活机会数、更新次数、路由与循环开销 | 计算与能耗分别计量 |
| 记忆 | 参数、持久状态、回放、外部历史及读写量 | 存储容量与访问成本分开 |
| 组织 | 复用、局部与长程关系、路由条件性、时间尺度及扰动响应 | 按匹配干预响应比较因果作用 |

跨系统比较采用能力、适应、可塑性、计算、记忆和复杂度的 Pareto 前沿。搜索可采用事先指定的标量适应度，最终评价分别展示其组成量。

## 7. 统计分析

1. 在最终数据产生前定义假设、主要终点、效应方向、阈值或等效区间、联合判据、种子数量、观察时长、排除条件和缺失处理。
2. 独立训练或演化种子是推断单位；同一运行内的时间步、事件和多个分支具有依赖性。重采样或置换应尊重这一层次。
3. 报告全部预定种子的值、配对差、分布与适当的不确定性区间。正负计数报告差值方向；显著性检验按预定统计模型执行。
4. 将探索数据与确认数据分开。机制、随机门控概率、资源权重和判据由探索数据确定，确认数据检验预定假设。新增分析明确假设与数据分工。
5. 无观测、未恢复、零分母和共同事件集为空有不同含义，分别保留原因与数量，不以零替代。
6. 未观察到符合阈值的恢复时，报告参考水平、观察窗口和可用时长。
7. 缺损数据、错配的干预和信息泄漏分别记录；完整但不支持假设的数据作为科学结果保留。

多假设分析应提前规定主次顺序和多重比较处理。环境、优化器、架构、预算及合理指标变体用于检验共同任务和共同测量所造成的假收敛。

## 8. 实验安排

### 比较设计与判据

研究方案先明确比较问题，再选择重复、变体与干预设计。各类比较按下表报告结果，并使用统计分析中预先指定的终点、效应方向和阈值或等效区间。

| 比较问题 | 研究设计与判据 |
|---|---|
| 单次观察 | 记录一次科学运行或定性观察的配置、环境、轨迹及目标现象，形成后续重复与干预的具体对象。 |
| 多种子复现 | 在同一实现与环境下使用独立训练或演化种子，报告全部预定种子的结果、配对差及其分布，检验目标现象的重复性。 |
| 单路线稳健性 | 在同一路线内改变环境、资源预算或实现变体，按共同操作定义重复比较，报告各条件下的效应与失效条件。 |
| 两路线独立出现 | 至少两条路线分别完成独立发现，在同一抽象层次、共同操作定义下检验相同现象，并区分预设组织与发现形成的组织。 |
| 跨路线因果响应 | 对不同路线施加匹配干预，保持各自共同历史与非目标因素，比较响应方向、大小及预定等效区间。 |
| 三来源因果对齐 | 工程、演化与生物三类来源在同一抽象层次对齐操作定义，比较三方的匹配干预响应及资源前沿。 |

跨路线比较考察机制的独立出现、预测力、资源权衡与替代解释。神经网络、连接组动力学、模块复用估计、多规模资源前沿及跨路线干预对齐使用对应的模型与观测数据开展实验。

实验推进按依赖组织：先确认输入与测量，再建立持续适应基线，随后隔离状态或更新机制，最后比较资源前沿与跨路线因果签名。比较原生模型时，对齐观测、状态、行动、反馈和随机过程的定义，再按共同干预条件比较结果。长期生态和开放式演化分别定义新颖性、复杂度、持续适应及课程变化的估计对象。

- **Rank and Gradient，Wu 等，2026。** 从 NTK 秩与梯度衰减研究非平稳强化学习中的可塑性损失。[ICLR 论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/2886558a03d11f95d4020a460fe4a390-Abstract-Conference.html)
- **Barriers for Learning，Joudaki 等，2026。** 分析梯度动力学受困于不变子流形的机制，提示静态压缩与持续可塑性可能冲突。[ICLR 论文](https://proceedings.iclr.cc/paper_files/paper/2026/hash/511c7fd69db9f1ce7492a57285975849-Abstract-Conference.html)
- **DiscoRL，Oh 等，2025。** 从多环境经验中元学习强化学习更新规则，并在未参与发现的基准上评估。[Nature 论文](https://www.nature.com/articles/s41586-025-09761-x)
- **DAL，Arnold、Suzuki、Arita、Yamazaki，2024。** 在二维导航任务中演化整合非奖励信息的局部调制更新。[ALIFE 论文](https://arxiv.org/abs/2404.12631)
- **HBL，Arnold、Suzuki、Arita，2026。** 研究奖励驱动学习向更少依赖奖励的学习机制过渡，涉及导航与四足运动任务。[作者摘要](https://pubmed.ncbi.nlm.nih.gov/42518295/)
