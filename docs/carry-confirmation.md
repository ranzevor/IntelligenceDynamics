# 循环状态重置确认实验

[English](en/carry-confirmation.md) · [研究设计](research.md) · [两轨迹试点](carry-study.md) · [研究结果](research-results.md)

## 研究问题

在固定的 DRQN、Foragax 环境与训练配置下，单次重置实时循环状态的正向奖励效应能否在新的独立训练轨迹中重复出现？

两轨迹试点中，索引 23、24 的重置减保留平均奖励差分别为 `+0.1903333333` 和 `+0.0617200000`。本次确认使用索引及种子 25–32，分析单位是八条独立训练轨迹。

## 固定设计

实验使用 `ForagaxSquareWaveTwoBiome-v11`、9×9 彩色观察和原生 DRQN。上游源码提交为 `9710f60fa30da5badc451ad7ce3ff296d5070830`，依赖锁对象为 `18b5340e7ce408d03ee518ac40419f4269c0a1c0`，Foragax 版本为 `0.55.0`。运行冻结项目源码提交 `991482ba8734a49187133d122cb10c577ef74a0d`（tree `70e4a9289d40f2c95afc3a7ff71912547a8cc685`），在 Linux x86_64、Python 3.12 与 JAX CPU 后端（`jax_enable_x64 = false`，8 个逻辑 CPU）执行，运行身份为 `4e64b8a3fa4cec7e41510a4c60af15b2e5024fe5f9cd009a96c4e4fd3415f853`。模型、优化器、探索与更新参数沿用试点配置。[实验配置](../configs/carry-confirmation.json)

每个种子先执行 150,000 次共同交互，再从同一完整状态建立两个分支。保留组继续使用实时循环状态，重置组在下一次策略计算前将 `agent_state.carry` 设为 `None`。两组各继续 150,000 次交互。

参数、优化器、经验回放、随机状态及环境状态具有共同分支起点。每个种子共 450,000 次有效交互，八个种子共 3,600,000 次。已完成的索引 23、24 作为探索结果单列，不计入确认推断样本。

## 主要终点与判据

对每个种子，在环境交互区间 `[150000, 300000)` 以 float64 归约计算

```text
R_i = 平均奖励(单次重置) - 平均奖励(保留状态)
```

确认判据同时要求八个 `R_i` 的算术均值大于零，以及正效应比例的单侧精确二项检验 `p ≤ 0.05`。检验的零假设为正效应概率不高于 `0.5`，正效应定义为 `R_i > 0`，零值计入非正。

在八条轨迹下，七条为正时单侧概率为 `9/256`，八条为正时为 `1/256`，六条为正时为 `37/256`。因此确认需要至少七条正效应及正的配对均值。

八条确认轨迹全部完成后，主要终点结果如下：

- **有效科研交互数**：`3,600,000`
- **配对差算术均值**：`+0.0219850000`（`+0.021985`）
- **正效应与零值计数**：`4 / 8` 为正（索引 27–30），`4 / 8` 为负（索引 25、26、31、32），`0` 个零值
- **单侧精确二项检验**：`p = 163/256 = 0.63671875`
- **正效应比例双侧 95% Clopper–Pearson 精确区间**：`[0.157013, 0.842987]`（`[0.1570127705, 0.8429872295]`）
- **预定确认判据**：未满足（`criterion_met = false`）

## 次要测量与过程特征

- **短期与后续固定响应窗**：重置后最初 1,024 次交互 `[150000, 151024)` 的八种子平均奖励差为 `+0.2849121094`（`6/8` 为正，范围 `-0.1855468750` 至 `+2.2363281250`，其中索引 27 从保留臂 `-0.6503906250` 升至重置臂 `+1.5859375000`）；其余区间 `[151024, 300000)` 的平均奖励差为 `+0.0201777468`（`4/8` 为正，范围 `-0.2564171410` 至 `+0.2818843304`），符号分布与主要终点一致。
- **25,000 步奖励窗口与 50,000 步更新诊断**：八条确认轨迹在 `[0, 150000)` 的六个 25,000 步窗口两臂逐字节一致（均值依次为 `0.315530`、`0.902760`、`1.183940`、`1.185120`、`1.338020`、`1.380030`）。分支后六个 25,000 步窗口的八种子平均奖励差（重置 − 保留）依次为 `+0.236880`（`7/8` 为正）、`-0.027440`（`3/8`）、`-0.111660`（`3/8`）、`-0.131450`（`4/8`）、`+0.016140`（`4/8`）和 `+0.149440`（`4/8`）。分支后三个 50,000 步窗口的八种子均值如下：

- **环境事件恢复与轨迹分叉**：沿用试点的 64 步完整窗口、90% 恢复阈值与 2,048 步观察期，八个种子在两臂的已恢复事件中位恢复步数均为 `64.0` 步。保留臂合计 `6,337` 个合格事件（恢复 `6,257`、未恢复 `80`，其中 `5` 个因到达 `300,000` 步终点截断）；重置臂合计 `6,302` 个合格事件（恢复 `6,220`、未恢复 `82`，其中 `10` 个因到达终点截断）。两臂边界后环境切换时间戳（64 步窗口）的 Jaccard 重叠仅 `0.047256`–`0.060458`（配对选取共享事件 `154`–`389` 个），显示单次状态重置迅速改变了随后访问到的位置与切换序列。
- **循环状态字节与时钟对齐**：八条确认轨迹均实际执行了非空 `agent_state.carry` 重置（差异路径仅 `["agent_state", "carry"]`）。重置前 `carry` 均为 `577,536` 字节（10 个 `float32` 张量叶，共 `144,384` 个元素），重置后为 `0` 字节，首次后续策略计算后重建为 `577,536` 字节（`initialized_carry = true`）。两臂首步 `agent_steps` 均由 `150,001` 推进至 `150,002`、`updates` 均为 `37,488`，首次后续梯度更新均发生于环境第 `150,004` 步（`agent_steps = 150,005`、`updates = 37,489`）。
- **有效交互与恢复重算计量**：有效科研交互为 `3,600,000` 次（`3,599,984` 次分块扫描交互累计纯扫描耗时 `11,789.82` 秒，另加 `16` 次分支首步交互）。确认实验共启动 `81` 个工作进程，其中 `80` 个成功完成（`72` 个阶段退出码 `10`、`8` 个终点退出码 `0`）；唯一一次中断发生在索引 28 的 `common` 阶段（`50,000` 步检查点保存后，日志输出至 `85,000` 步），从 `50,000` 步检查点恢复带来 `35,000` 次已记录重复交互（未落盘重算上界 `< 50,000` 次），不增加独立样本数。已完成工作进程累计墙钟 `21,047.85` 秒（含中断跨度总墙钟 `22,908.42` 秒）、用户态 CPU `30,542.71` 秒、内核态 CPU `3,784.37` 秒，单进程最大 RSS 为 `6,542,648 KiB`（范围 `3,999,488`–`6,542,648 KiB`）。

## 解释与后续设计

固定配置下的八轨迹确认实验未能重复试点呈现的长期正向奖励优势（`4/8` 为正，`p = 0.63671875`）。短期指标提示了一个具体的机制线索：在边界后前 `1,024` 步和首个 `25,000` 步窗口内，重置组分别在 `6/8`（均值 `+0.284912`）和 `7/8`（均值 `+0.236880`）个种子中高于保留组，尤其是当边界处处于负回报状态时（如索引 27），清除滞留 `carry` 能使行为迅速脱离低谷。但由于两臂在分支后均保留经验回放写入与每 4 步一次梯度更新，单次实时状态扰动随后通过改变采样经验（切换时间戳重叠 `< 6.1%`）使两条学习轨迹发生显著的双向分化（`R_i` 分布于 `-0.254400` 至 `+0.280133`）。

因此，将`保留／重置实时循环状态`与`继续学习／冻结参数更新`在 `150,000` 步共同起点上展开为 `2×2` 析因对比，是把瞬时实时控制效应与后续个体学习轨迹偏移分离开的直接下一步。
