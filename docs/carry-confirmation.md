# 循环状态重置确认实验

[English](en/carry-confirmation.md) · [研究设计](research.md) · [两轨迹试点](carry-study.md)

## 研究问题

在固定的 DRQN、Foragax 环境与训练配置下，单次重置实时循环状态的正向奖励效应能否在新的独立训练轨迹中重复出现？

两轨迹试点中，索引 23、24 的重置减保留平均奖励差分别为 `+0.1903333333` 和 `+0.0617200000`。本次确认使用索引及种子 25–32，分析单位是八条独立训练轨迹。

## 固定设计

实验使用 `ForagaxSquareWaveTwoBiome-v11`、9×9 彩色观察和原生 DRQN。上游源码提交为 `9710f60fa30da5badc451ad7ce3ff296d5070830`，依赖锁对象为 `18b5340e7ce408d03ee518ac40419f4269c0a1c0`。模型、优化器、探索与更新参数沿用试点配置。[实验配置](../configs/carry-confirmation.json)

每个种子先执行 150,000 次共同交互，再从同一完整状态建立两个分支。保留组继续使用实时循环状态，重置组在下一次策略计算前将 `agent_state.carry` 设为 `None`。两组各继续 150,000 次交互。

参数、优化器、经验回放、随机状态及环境状态具有共同分支起点。每个种子共 450,000 次有效交互，八个种子共 3,600,000 次。已完成的索引 23、24 作为探索结果单列。

## 主要终点与判据

对每个种子，在环境交互区间 `[150000, 300000)` 以 float64 归约计算

```text
R_i = 平均奖励(单次重置) - 平均奖励(保留状态)
```

确认判据同时要求八个 `R_i` 的算术均值大于零，以及正效应比例的单侧精确二项检验 `p ≤ 0.05`。检验的零假设为正效应概率不高于 `0.5`，正效应定义为 `R_i > 0`，零值计入非正。

在八条轨迹下，七条为正时单侧概率为 `9/256`，八条为正时为 `1/256`，六条为正时为 `37/256`。因此确认需要至少七条正效应及正的配对均值。

报告八条配对差、配对均值、正值和零值数量、单侧检验概率，以及正效应比例的双侧 95% Clopper–Pearson 区间。固定八条轨迹全部完成后统一判定结果。

## 次要测量

- 重置后最初 1,024 次交互，即 `[150000, 151024)` 的平均奖励差。
- 后续区间 `[151024, 300000)` 的平均奖励差。
- 每 25,000 次交互的奖励曲线，以及分支后每 50,000 次交互的损失、绝对 TD error 和 weight change 均值。
- 沿用试点的完整事件窗口、恢复水平和观察期，报告各臂事件、恢复和未恢复数量。
- 重置前、重置后及首次后续策略计算后的循环状态字节数，以及各执行阶段的时间和峰值内存。

上述次要测量用于描述响应过程。主要确认结论使用上一节固定的联合判据。

## 数据与分析

每个种子保存五条类型化轨迹、共同检查点和分支检查点。配对分析核对两臂的共同前史、原生状态来源和实际干预路径。空操作作为该种子的观测结果保留。

分析从最终 NPZ 重新计算主要和次要终点，记录运行源码、配置及依赖身份，并保存各轨迹的结果。中断重算量与有效交互量分别记录。运行、续跑和资源设置见[贡献指南](../CONTRIBUTING.md#循环状态确认实验)。
